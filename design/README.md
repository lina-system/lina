# Generated UI template

`template.go` embeds the token CSS generated by `scripts/tokens.mjs`, shared base
styles, fixed local mock interactions and Pretendard Variable 1.3.9. The font is
from [Pretendard](https://github.com/orioncactus/pretendard/tree/v1.3.9), under the
bundled [OFL license](fonts/OFL.txt). Pages never fetch fonts.
The WOFF2 SHA-256 is
`9599f12fd42fc0bce1cd50b47a0c022e108d7aa64dd0d1bb0ed44f3282d900b4`.

`MockPage` receives a checked XHTML fragment. It embeds the fixed CSS, font and
script; CSP permits their exact hashes and denies connections, frames, forms,
objects and remote resources. `MockFrame` wraps it with `sandbox="allow-scripts"`,
without same-origin, navigation, forms, downloads or popups. The parent must not
add a bridge or credentials. Phone and desktop widths are 390 and 1280 points.

`MiniAppFiles` supplies the same tokens, base styles and font as immutable files
for mini-app builders. The mini-app host owns its separate origin, gateway,
client library and response policy; none of those authorities enter a mock.
The accepted mock bundle includes a starter built with this shared template for
handoff to a mini-app worker. Its local sample interactions remain mock behavior
until the worker implements declared reads and requests through that host.
