# In-Session Commands

Use `/help` in the current surface. The registry is `hermes_cli/commands.py`; aliases and platform gates determine availability.

- `/model` changes the session model; keep LINA inference on OCX.
- `/compress` compresses context when needed. Do not manually rewrite past messages to recover space.
- `/skin` selects the CLI palette; use the safe config writer when applying a requested change for the owner.
- `/voice` controls voice behavior only when the necessary services are configured.

Prompt-affecting changes normally apply to the next session. Do not recommend mid-conversation reloads merely because an old guide lists them. Check the registry and handler before giving arguments for any additional slash command.
